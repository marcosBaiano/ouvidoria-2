Sistema de Ouvidoria Corporativa

Visão Geral
O Sistema de Ouvidoria Corporativa é uma aplicação web desenvolvida para centralizar, gerenciar e acompanhar manifestações como denúncias, sugestões e feedbacks, garantindo segurança, anonimato e transparência organizacional.

Arquitetura da Solução
Usuário ⇄ Front-end ⇄ API (PHP) ⇄ Banco de Dados (MySQL)

Responsabilidades no Projeto
Front-end (Minha atuação):
- Desenvolvimento de interfaces responsivas e acessíveis
- Implementação de fluxos de navegação
- Consumo de APIs via JavaScript
- Padronização visual e experiência do usuário

Estrutura de Diretórios
OUVIDORIA2.0/
assets/
database/
public/

Stack Tecnológica
Front-end: HTML5, CSS3, JavaScript
Back-end: PHP, MySQL

Execução do Projeto
1. Coloque o projeto em htdocs/
2. Inicie Apache e MySQL
3. Importe database/schema.sql
4. Acesse ***

Funcionalidades
- Registro de manifestações
- Acompanhamento de solicitações
- Dashboard administrativo
- Integração com API
